# TARU

Health app monorepo — Flutter mobile client with Firebase Auth.

## Structure

| Path | Purpose |
|------|---------|
| `mobile/` | Flutter app (iOS + Android) |
| `docs/` | Project docs |
| `assets/` | Shared assets |

## Mobile setup

```bash
cd mobile
flutter pub get
flutterfire configure   # if regenerating Firebase options
flutter run
```
