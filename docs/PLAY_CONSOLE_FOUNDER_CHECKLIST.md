# PLAY_CONSOLE_FOUNDER_CHECKLIST

Internal founder checklist. No uploads or agreement acceptance by engineering
automation.

## Account

- [ ] Google Play developer account active
- [ ] Developer identity verification complete (as required by Google)
- [ ] Payment profile / account fees settled if required

## App record

- [ ] Create Play Console app for package `com.taru.health`
- [ ] Choose app / game category appropriately (health-related)
- [ ] Complete required store listing drafts (no guessing Privacy Policy URLs)

## Signing

- [ ] Create TARU **upload** keystore in a secure founder-controlled location
- [ ] Configure local `mobile/android/key.properties` (gitignored)
- [ ] Enroll **Play App Signing** (Google holds app signing key; upload key used by founder)
- [ ] Keep upload key backup offline; never commit to Git

## Testing track

- [ ] Create Internal testing track
- [ ] Add tester emails / Google Groups
- [ ] Upload AAB only after Privacy Policy URL and Data safety drafts are ready enough for the chosen track

## Compliance forms (legal-owned answers)

- [ ] Privacy Policy URL (live)
- [ ] Data safety form
- [ ] Support / contact information
- [ ] Content ratings questionnaire
- [ ] Target audience / news apps / COVID declarations as applicable

## Do not

- Upload from automation in this foundation phase
- Accept Play agreements without founder review
- Invent Privacy Policy or Data safety answers
